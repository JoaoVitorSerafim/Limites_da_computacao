# Limites da Computação

Projeto acadêmico desenvolvido para estudar problemas computacionais e seus limites.

## Tema

Problema do Caixeiro Viajante (TSP), comparação entre algoritmos de força bruta e vizinho mais próximo, Problema da Parada e classes P e NP.

## Tecnologias utilizadas

- Python
- Matplotlib

## Estrutura do projeto

- `src/`: implementação dos algoritmos.
- `tests/`: testes do projeto.
- `resultados/`: resultados das medições de desempenho.
- `docs/`: documentação e pseudocódigo.

## Algoritmos implementados

- Força bruta: busca a melhor rota entre as possibilidades.
- Vizinho mais próximo: constrói uma rota escolhendo a cidade não visitada mais próxima.

## Objetivo

Comparar o tempo de execução e a qualidade das soluções dos algoritmos, observando como o crescimento do número de cidades afeta o desempenho.

## Execução

Os programas podem ser executados utilizando Python a partir da pasta principal do projeto.
